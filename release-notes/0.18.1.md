- Worktrees inside the main checkout at `.worktrees/<name>/` are supported. If your app moves its worktrees there, make the primary checkout's dev server, lint, format and test globs ignore `.worktrees/` (for Vite, `server.watch.ignored: ['**/.worktrees/**']`), because the primary's containers mount the whole tree. Declare `install` in `devkit.config.mjs` if you have not already, so a nested worktree gets its own `node_modules` instead of silently using the primary checkout's. The README's "Limits and gotchas" has the details.
- The bundled VS Code browser bridge is rebuilt from current source. Its behaviour and version (0.3.0) are unchanged, so an installed copy is not reinstalled.
