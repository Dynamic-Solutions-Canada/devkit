- **Each locale's hero can show its own capture:** a hero's `source` may now contain `{locale}` (for example `raw/microsoft/{locale}/00-flyout-dark.png`), so every listing locale shows Windows and the app in its own language. `devkit-store-hero --check` fails and names each listing locale without its own capture. A plain `devkit-store-hero` run draws a missing locale from the en-US capture as a preview and warns. A `source` without `{locale}` works as before.
- **Captures at 200% display scale keep the same layout:** `hero.crop` is now in logical pixels. That is identical at 100%, so existing manifests need no edit, and a 200% capture uses the same crop values and draws sharper.
- **Fewer headline words left alone on a line:** when balanced line breaks strand a word, the headline is broken again into the same number of lines to keep it with its neighbours, never by running one sentence into the next. The size limit for avoiding a lone word goes from 10 to 15 percent smaller.
- **Some heroes must be re-rendered after the bump:** `check:hero` fails until you run `devkit-store-hero` and commit the new images. This affects 16 heroes in seven apps: DisplaySwitchr (de-DE), ImmichDrive (ja-JP), ChatMixr (es-ES, pt-BR), Persistent (en-US, es-ES, de-DE, pt-BR), Little Launcher (es-ES, pt-BR), Tray Control for WSL (es-ES, fr-FR, pt-BR) and Repilot (fr-FR, de-DE, pt-BR). PrintStream is unchanged.
- **Coming from an older pin (v0.16.2 to v0.28.0):** read those versions' notes as well. Nothing in this version needs an edit outside Store heroes.
