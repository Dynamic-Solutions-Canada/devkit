- **Paseo support is removed:** `devkit-init` no longer writes or checks `paseo.json`, and `devkit cleanup` no longer checks Paseo workspaces. An existing `paseo.json` is left as it is; delete it, since devkit no longer reads it.
- **`generated.paseo` is no longer accepted:** if `devkit.config.mjs` still sets `generated: { paseo: true }` or `generated: { paseo: false }`, every devkit command that reads the config, including `devkit-init --check`, stops with an error naming the option until you delete the `paseo` key.
- **`devkit cleanup --paseo` is refused as an unknown option:** a worktree teardown hook that passes it must drop the flag and run `devkit cleanup --yes`. Plain `devkit cleanup` and `--yes` work as before.
- **Coming from an older pin (v0.16.2 to v0.30.0):** read those versions' notes as well.
