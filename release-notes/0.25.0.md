- Nothing changes for an app that only bumps its pin, and nothing needs regenerating.
- **Several Android apps from one brand:** `targets.android` in `assets/brand/icons.json` can now be a list, one entry per app, each with its own `res` folder and options. Set `play` to false for an app with no Play listing, or give it its own `playPath`. `devkit-icons --check` and the superseded-file check cover every app. See "Icons" in the README.
- **A variant icon for one target:** a target entry's `masters` block can point `icon`, `maskable` or `mono` at other SVG files, for example a variant for a second app. Masters it leaves out stay the shared ones.
- `devkit-icons` now fails when two outputs would write the same file, instead of letting the later one silently overwrite the earlier one.
- The dev compose template and README explain how to keep the container's HOME writable when an app mounts a volume under it.
