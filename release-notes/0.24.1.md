- **Regenerate your third-party notices:** run `devkit-notices` and commit the result. It no longer lists packages that only an optional peer and a dev dependency reach, which `npm ls --omit=dev` counted as shipped. TypeScript was the common case: i18next, react-i18next, Prisma and Radix declare it, or `@types/react-dom`, as an optional peer, so it showed up in notices for bundles that never include it. A package is still listed when a shipped dependency needs it.
- `devkit-notices` now reads `package-lock.json` instead of running `npm ls`. It needs lockfileVersion 2 or 3 (npm 7 or later), and it fails with "run npm ci" when a required dependency is not installed.
