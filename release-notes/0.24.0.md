- **Action for apps that deploy an nginx site file:** add `DEPLOY_NGINX_SITES_DIR` to your untracked `.env`, set to the server's nginx sites folder. It no longer has a default, so `npm run deploy:prod` now stops before contacting the server until it is set, and it must be an absolute path. Apps with `deploy.site: null` need nothing.
- Keep the value in `.env`, not in `devkit.config.mjs` or your docs: it is a real server path, and tracked files are public in a public repo. Use a placeholder such as `/srv/nginx/sites` when documenting it.
- The generated `scripts/deploy/deploy-over-ssh.mjs` changes, so run `npm exec devkit-init` after bumping and commit the result; `devkit-init --check` fails until you do.
