- **Headlines no longer leave a single word alone on a line when a slightly smaller size avoids it:** when the largest size that fits would strand one word on its own line (for example "Every printer, / every / project, on / every device."), `devkit-store-hero` now sets the headline or subline up to 10 percent smaller if that keeps the word with its neighbours. Text that already broke cleanly is unchanged.
- **Some heroes must be re-rendered after the bump:** a hero whose headline left a single word alone may now draw differently, so `devkit-store-hero --check` (your `check:hero` script) fails until you run `devkit-store-hero` and commit the new images. Today that affects six apps: PrintStream (en-US), ChatMixr (pt-BR), Tray Control for WSL (de-DE), Repilot (pt-BR), ImmichDrive (fr-FR, ja-JP) and Persistent (de-DE). DisplaySwitchr and Little Launcher are unchanged.
- **Coming from v0.20.3 to v0.27.0:** read those versions' notes as well; only the hero re-render above needs action from an app that only bumps its pin.
