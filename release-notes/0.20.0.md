- **`devkit-icons`** makes every icon size your platforms need from your SVG masters in `assets/brand/` (`icon.svg`, plus `icon-maskable.svg` for the web and `icon-mono.svg` for Windows and Android), and `devkit-icons --check` fails in `validate` when a committed icon no longer matches. Name your targets and folders in `assets/brand/icons.json`, add `@resvg/resvg-js` as an exact dev dependency, and replace your own icon script with `devkit-icons`. game-is-up's outputs come out byte-identical once its masters move to `assets/brand/`. Add it to `lefthook.yml` with your exceptions on the run line, for example `--allow android/app/debug.keystore`; see "Refusing secrets and oversized files at commit time" in the README for the snippet.
