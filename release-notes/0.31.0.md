- **`paseo.json` is no longer generated unless you ask for it:** `devkit-init` now writes and checks `paseo.json` only when `devkit.config.mjs` sets `generated: { paseo: true }`. After the bump an existing `paseo.json` is left as it is and `check:devkit` stops checking it; delete it if the app no longer uses Paseo, or add `generated: { paseo: true }` to keep it generated. An app that already set `generated: { paseo: false }` can drop that line.
- **Coming from an older pin (v0.16.2 to v0.29.0):** read those versions' notes as well.
