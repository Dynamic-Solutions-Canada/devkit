- **Xbox Game Bar widget icons:** set `"gameBarIcons": "<dir>"` in the Windows target to also write a widget's `icon.targetsize-<size>.png` set (16, 20, 24, 32, 44 and 256 px) from `icon.svg`, and `icon.light.targetsize-<size>.png` from `icon-mono.svg` drawn dark for Game Bar's light theme. Point it at the `Icons` folder in the widget's PublicFolder. Nothing changes until you set it.
